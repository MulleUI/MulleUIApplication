# 𝄢 MulleUIApplication

#### 𝄢 MulleUIApplication provides abstract classes like UIApplication and UIEvent

This library lays the ground work for window and event handling. It isn't tied
to any platform or graphics library. UIWindow is a protocol, that will get
fleshed out by MulleUIWindow (and MulleGLFWWindow).


### You are here

![Overview](overview.dot.svg)


MulleUIApplication is based on [MulleObjCLockFoundation](//github.com/MulleFoundation/MulleObjCFoundation).
Foundation datatypes like `NSString` are not available.
